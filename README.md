# Octalve Booking

Independent booking and enquiry scheduling product.

This repository is being established with a review-first release flow. Initial `main` is an administrative placeholder, **not a deployable application**. The full source is prepared on `phase/00-booking-shell`; `review/booking` will be the Vercel Preview branch. `main` will receive the tested application after qualification and approval.

No runtime dependency on Octalve Finance or Octalve EMR.
