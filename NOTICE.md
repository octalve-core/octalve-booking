Octalve Booking — initial independent application and UI foundation, 2026.

This project is independent of Octalve Finance and Octalve EMR. The colors and general user-experience patterns are informed by the brand's existing products, but the interface source in this package was newly authored, not copied from the older applications. The abstract blue Octalve mark is a temporary local vector asset. No connected product's source code, database, keys or local environment is required to run it.

Illustrative customer records are enabled only in the explicitly local review HTML and are not presented in hosted workspace UI. The included front-end pages are not connected to a live reservation, merchant-payments or calendar system; production booking and payment submission are disabled at the server boundary. The data model and SQL are subject to security and database review before real deployments with personal data.
